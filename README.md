# SFML Projects

Collection of game-development projects and graphics programming experiments built with C++ and SFML. These projects explore topics such as game loops, collision detection, physics simulation, particle systems, and real-time input handling.

## Tech Stack
- C++
- SFML 2.5.1
- Visual Studio

## Projects

### SFML Pong
Classic paddle-and-ball game featuring collision detection, scoring, and real-time keyboard input.

### Physics Playground
Experimentation with object movement, collision response, and basic physics concepts.

### Particle Shooter
Particle spawning and destruction mechanics driven by user input and game events.

### Multiple Balls
Simulation of multiple moving objects with independent movement and collision behavior.

### Auto Moving Ball
Exploration of movement, velocity, and boundary interactions.
